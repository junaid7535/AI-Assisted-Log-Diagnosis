# GSoC Proposal Outline

## Problem
Manual log diagnosis increases MTTR.

## Goal
Build an AI-assisted log diagnosis and root-cause detection toolchain.

## Deliverables
- Log parser and preprocessing pipeline
- Anomaly detection module
- Log clustering module
- RCA report generator
- Evaluation dataset and metrics
- API and CLI

## Stretch Goals
- LLM-based RCA reports
- Timeline correlation with metrics/traces
- Graph-based dependency RCA
